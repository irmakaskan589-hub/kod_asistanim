# Projenin Adı: Kod-Asistan v0.1

## Projenin Amacı: 
Kullanıcılara günlük işlerinde (hesaplama, selamlama vb.) yardımcı olacak bir dijital asistan tasarlamak.

## Projenin Hedefleri: 
* v1.0 Sürümü ile Akıllı Menü özelliğinin eklenmesi
* v2.0 Sürümü ile Veri Saklama ve geçmiş kaydetme özelliğinin kazandırılması

## Projenin Kapsamı ve Kritik Eşik Mantığı: 
Proje kapsamında kullanıcının girdiği girdilerin belirlenen kritik eşik değerini geçip geçmediğini kontrol eden sözde kod mantığı entegre edilmiştir.

## Kaynakça
* Millî Eğitim Bakanlığı, Programlama Temelleri Ders Kitabı, Algoritmik Düşünme ve Tasarım Modülü.
